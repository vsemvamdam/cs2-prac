# CS2 Prac

Локальный сервер CS2 для изучения смоков и префаера на **официальных картах текущей версии игры**.
Карты из Мастерской обновляют редко, и после патчей раскидки на них перестают совпадать с матчмейкингом.
Здесь сервер запускает те же карты, что и в игре, а после каждого патча сам перепроверяет раскидки.

## Что внутри

- **Табло-меню в игре.** `E` открывает табло перед игроком. Пункты выбираются цифрами `1–9`
  (бинды `slotN; css_N`, на официальных серверах цифры работают как обычно), выстрелом по строке
  или `!N` в чате.
- **Раскидки.** 9 карт пула (CS2-annotations). Выбрал раскидку — телепорт на точку броска,
  прицел наведён, граната в руке, маркер «куда смотреть» и подпись над точкой падения.
  После броска сервер пишет «Точно» или «Мимо на N юнитов». Свои раскидки можно сохранять.
- **Проверка после патча.** Сервер сам повторяет эталонные броски и показывает,
  какие раскидки теперь падают не туда.
- **Префаер.** Маршруты с ботами из [OpenPrefirePrac](https://github.com/lengran/OpenPrefirePrac).
- **Оружие и скины.** Любое оружие с любым скином (Dragon Lore, Howl, Fade…), ножи и агенты.
  Выбор выдаётся при каждом возрождении, в префаере тоже. Скины видны только на этом сервере.
- **Смена режима без переподключения.** «Смоки ⇄ префаер» из меню или ярлыком: плагины
  переключаются на лету, карта перезагружается, игрок остаётся на сервере.

## Установка (Windows)

1. Скачай архив `CS2Prac.zip` (или собери его, см. ниже) и распакуй в любую папку.
2. Запусти `1. Установить или обновить.cmd`. Скрипт через SteamCMD ставит выделенный сервер CS2
   (больше 60 ГБ), Metamod:Source, CounterStrikeSharp, MatchZy, OpenPrefirePrac и плагин CS2 Prac,
   а на рабочем столе создаёт ярлыки «CS2 Prac — смоки» и «CS2 Prac — префаер».
3. Запусти ярлык. Подробности — в `installer/Как пользоваться.txt`.

После патча CS2 снова запусти `1. Установить или обновить.cmd`.

## Сборка

Нужен .NET 10 SDK.

```bash
tools/pack.sh          # плагин + папка для ПК: dist/CS2Prac.zip
```

Данные раскидок и скинов пересобираются из исходных репозиториев:

```bash
python3 tools/build_data.py <CS2-annotations> <cs2-WeaponPaints> plugin/CS2Prac/data
```

## Устройство

| Путь | Что это |
|---|---|
| `plugin/CS2Prac/` | Плагин CounterStrikeSharp: табло (`BoardMenu.cs`, `WorldText.cs`), раскидки и проверка (`Lineups.cs`), скины (`LoadoutLogic.cs`), смена режима (`ModeSwitch.cs`) |
| `plugin/CS2Prac/data/` | Раскидки по картам, скины, агенты |
| `installer/` | PowerShell-лаунчер и `.cmd`-ярлыки: установка, запуск, диагностика |
| `tools/` | Сборка данных и архива |
