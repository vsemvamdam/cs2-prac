# План тестов CS2 Prac

Прогон 7 ноября 2026, CS2 1.41.9.6, Windows + локальный сервер, карта Mirage. Проверка — в игре через управление
ПК (клавиши, мышь, чат) и по журналу бросков `logs/throws.jsonl`. «✓» — прошло, «✗» — баг (см. `bugs.md`),
«—» — не проверялось в этом прогоне.

## F01. Запуск и подключение
| ID | Сценарий | Итог |
|---|---|---|
| F01-H1 | Сервер выключен, игра закрыта → ярлык «Смоки»: сервер стартует, игра запускается | ✓ |
| F01-H2 | Игра запущена этим же ярлыком → бинды 1–9 загружены (цифры выбирают пункты) | ✓ |
| F01-E1 | Игра после запуска ярлыком сама подключается к серверу | ✗ B06 |
| F01-H3 | Подключение через Играть → глобус → Избранное → CS2 Prac | ✓ |
| F01-H4 | Сервер запущен, ярлык другого режима → режим меняется на лету, игрок остаётся на сервере | ✓ (5 ноября) |
